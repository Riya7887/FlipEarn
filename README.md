# FlipEarn
FlipEarn is platform where users can buy and sell social media profiles securely.


## Features
- Buy social media profiles
- Sell social media profiles
- User authentication
- Profile listing
- Secure Transactions


## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB


## Installation
- Run npm install
- Run npm run dev


## Future Features
- Chat between buyer and seller
- Payment Gateway
- Admin Dashboard
